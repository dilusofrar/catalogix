# Catalogix

Catálogo digital de produtos com sistema de cotação/carrinho integrado — SPA em React (sem build step), feita para uma apresentação acadêmica.

## Como visualizar

Basta abrir o arquivo [`index.html`](index.html) em qualquer navegador moderno, ou publicar a pasta via GitHub Pages.

## Funcionalidades

- Busca instantânea por nome ou SKU
- Filtros por categoria, faixa de preço e disponibilidade em estoque
- Ordenação por menor/maior preço e nome
- Modal de visualização rápida com especificações técnicas
- Gaveta lateral de carrinho com subtotal, desconto simulado e total
- Modal de confirmação com resumo da cotação

## Stack

React 18 + Babel Standalone (via CDN) e CSS puro, sem etapa de build.
